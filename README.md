Distance Between Two Points
Description
This project is a Python program that calculates the Euclidean distance between two points on a coordinate plane.

The program asks the user to enter the coordinates of two points and then uses the distance formula to calculate the distance between them.

How to Run the Program
Make sure Python is installed on your computer.

Save the program as distance.py.

Open a terminal or command prompt in the folder containing the file.

Run the program using:

python distance.py

Input Needed
The program requires four values:

x1 – x-coordinate of the first point

y1 – y-coordinate of the first point

x2 – x-coordinate of the second point

y2 – y-coordinate of the second point

For example:

Enter x1: 2
Enter y1: 3
Enter x2: 6
Enter y2: 6

Sample Output
The distance between the two points is: 5.00
